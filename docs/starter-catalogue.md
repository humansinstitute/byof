# Workshop starter Napplets

The starter catalogue contains exactly five self-contained Napplets:

- **Cashu wallet** is a real Minibits Ippon REST client. It can create or reconnect a short-lived Ippon wallet, refresh balances, request a Lightning deposit and check until Ippon reports `ISSUED`. The Ippon access key and pending quote are stored only through the Napplet storage namespace, which the host derives from Canvas, project and authenticated user. They are not shared through Canvas datasets or embedded in source. The public `https://ippon.minibits.cash` deployment did not return browser CORS headers for `Origin: null` when checked on 2026-10-17, so it cannot currently be used directly from the opaque Napplet frame. A self-hosted or public Ippon deployment that explicitly permits the null origin and `Authorization` header works with the starter. The smallest alternative is a host-mediated Ippon capability that retains the bearer key server-side and returns only wallet details, invoice, deposit state and balance.
- **Bush Bash Nostr** reads verified kind-1 events with `#t: ["bussobushbash"]` through `napplet.relay.query` and `napplet.relay.subscribe`. It distinguishes complete empty results from partial, failed and truncated reads and renders event content only with text DOM APIs.
- **Bitcoin spinner** visibly spins and always answers the displayed question “Should I buy bitcoin?” with “Yes”.
- **100 D6 rolls** uses rejection sampling over `crypto.getRandomValues` to produce exactly 100 independent values in the inclusive range 1–6 and displays both rolls and counts.
- **21-sat Pong** resolves `bitcoinbushbash@walletofsatoshi.com` through LNURL-pay and requests exactly `21000` millisatoshis. It exposes the returned BOLT11 as a `lightning:` link. Wallet of Satoshi's callback response did not include a credential-free settlement check when tested on 2026-10-17, so invoice creation never unlocks the game. The smallest safe follow-up is a host method that records the exact invoice/payment hash against the authenticated project, checks settlement with trusted provider authority and returns only verified paid/unpaid state. The included Pong implementation already supports keyboard and pointer/touch control, but remains hidden until that verified signal exists.

Todo, Meme Generator and the other historical starters are no longer offered in the catalogue. Existing projects and immutable revisions are independent database records and are not removed or rewritten when catalogue entries change.
